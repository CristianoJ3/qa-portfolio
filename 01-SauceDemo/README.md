# Cypress Test Automation — SauceDemo

Este é um projeto pessoal desenvolvido com o objetivo de praticar e aprimorar 
conhecimentos em automação de testes de software, utilizando o framework Cypress e a linguagem JavaScript.

Os testes foram desenvolvidos no site público SauceDemo (https://www.saucedemo.com/), 
contemplando cenários como login, logout, tratamento de credenciais inválidas e conclusão de uma compra.

O projeto faz parte dos meus estudos na área de Quality Assurance (QA), com foco no desenvolvimento de 
habilidades em automação de testes e na preparação para atuar profissionalmente na área.
