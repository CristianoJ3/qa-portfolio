# QA Portfolio

Este repositório reúne projetos práticos de Quality Assurance (QA), desenvolvidos com o objetivo de demonstrar 
conhecimentos em testes de software, técnicas de validação e boas práticas da área.

Objetivos:

Demonstrar conhecimentos e habilidades em diferentes atividades de Quality Assurance, incluindo:

- Testes manuais e funcionais
- Elaboração de casos de teste
- Identificaçãp, registro e análise de defeitos
- Testes exploratórios
- Testes de API
- Automação de testes

Tecnologias e ferramentas utilizadas:

- Cypress: automação de testes End-to-End (E2E)
- JavaScript: implementação de testes automatizados e validações
- Postman: execução e automação de testes de API
- Git e GitHub: versionamento e documentação dos projetos

Organização do repositório:

- 01-SauceDemo: automação de testes funcionais em uma aplicação de e-commerce
- 02-BugBank: testes funcionais e identificação de comportamentos inesperados em uma aplicação bancária
- 03-API-Testing: testes de API utilizando Postman e JavaScript

Sobre os projetos:

Cada projeto busca reproduzir situações encontradas no ambiente profissional, priorizando organização, documentação, clareza na descrição dos cenários e pensamento crítico durante a execução dos testes.

Este portfólio será atualizado gradualmente conforme novos conhecimentos, técnicas e ferramentas forem estudados e aplicados.
